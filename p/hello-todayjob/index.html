为什么要做 TodayJob

找工作最难的部分，往往不是面试，而是信息。

厦门的开发岗位分散在各个招聘平台、公司官网和招聘群里。每天刷一遍，费时费力，还容易漏掉刚刚发布的机会。TodayJob 想做的事情很简单：

每天北京时间 17:00，把厦门当天新发布的开发岗位集中整理成一张表。

不用注册，不用登录，打开网页就能看到今天有哪些公司在招人。

每天 17:00，自动更新

TodayJob 的更新流程是全自动的：

  1. 采集：每天 17:00 通过 GitHub Actions 调用智联招聘接口，抓取当天厦门地区发布的开发岗位。
  2. 分析：按公司聚合，统计每家公司当天发布的职位数量，并保留地点、岗位链接和发布时间。
  3. 发布：自动生成文章，提交到博客源码分支 main。
  4. 部署：构建产物推送到 gh-page 分支，由 Vercel 自动完成部署。

整个过程不需要人工干预，你看到的永远是最新一天的汇总。

表格字段说明

字段含义
公司名称发布岗位的公司
今日职位发布数量该公司当天在厦门发布的开发岗位数量
地点岗位所在区域
岗位链接任意一个当天岗位的详情页链接
发布时间岗位首次发布的时间

一点使用建议

  • 每天 17:00 后查看：当天的岗位已经汇总完成。
  • 优先看职位数量多的公司：通常意味着团队正在扩张，HC 更充足。
  • 尽早投递：开发岗位的窗口期往往很短，当天发布的岗位竞争最小。
  • 结合岗位链接确认细节：表格负责发现机会，具体要求仍以原岗位页面为准。

关于数据

TodayJob 只做公开岗位信息的聚合与展示，不保存简历，也不参与招聘流程。所有岗位信息均来自公开招聘接口，最终解释权归原招聘平台与发布公司所有。

如果你发现数据有误，或者希望增加筛选维度，欢迎在 GitHub 仓库 提 Issue。
