一键生成智联招聘 Cookie

手动登录智联招聘后，用下面这个书签读取当前登录 Cookie，并直接验证是否有效。全程只在你的浏览器里完成。

第一次使用：把按钮拖到书签栏

🔑 生成 Cookie 打开智联招聘

拖动不成功时，可以复制书签代码，新建一个书签，把代码粘贴到网址栏。

每次更新 Cookie

  1. 在电脑浏览器打开 智联招聘 并登录。
  2. 确认地址栏是 www.zhaopin.com，然后点击书签栏里的「生成 Cookie」。
  3. 弹窗会自动读取并验证登录态。点「复制 Cookie」。
  4. 打开 GitHub 仓库的 Settings → Secrets → Actions，更新 ZHAOPIN_COOKIE。

Cookie 等同于账号登录凭证。本工具只在 zhaopin.com 页面运行，不会把 Cookie 上传到 TodayJob 或任何第三方；请不要把 Cookie 发给别人。

常见问题

提示缺少 at / rt？
说明当前页面没有登录态。请先在智联招聘完成登录，并回到 www.zhaopin.com 首页再点书签。

验证返回 0 条？
Cookie 可能已经过期。重新登录后再生成一次；如果仍然为 0，可以先复制，采集脚本会自动判断并回退匿名模式。

书签点击没反应？
